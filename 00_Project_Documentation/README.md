# Project Documentation

This folder contains the main research planning and coordination documents for the Automotive Application Security Testing System project.

## Files

### project_alignment.md

Shows the alignment between the research problems, research gap, research objectives, methodology, technical approach, evaluation and expected outcome.

### research_direction.md

Describes the research focus, proposed system, methodology, development model, evaluation plan and controlled testing scope.

### team_contributions.md

Records the responsibilities and contributions of each Group AD member.

## Project Status

The project is currently at the research proposal and preliminary design stage.

The next stages will include prototype development, controlled testing, evaluation and documentation of findings.
