# References

This folder holds the references and supporting sources backing up our research proposal. The idea is simple: whatever gets cited in the actual proposal should be traceable back to something real sitting in this folder — no citation should exist in the report without a matching source here, and vice versa.

## What belongs here

We expect this to eventually include:

- Academic journal articles and conference papers used across our literature review (Chapter 2)
- NIST guidance, since our development model is guided by the NIST Secure Software Development Framework (SSDF)
- Automotive cybersecurity research specific to the problem space we're addressing
- Application security testing studies (SAST, DAST, and hybrid approaches)
- Secure SDLC and DevSecOps literature that supports our methodology choices

## A quality note

This folder is intentionally left lean for now rather than padded out with sources we haven't actually used — every reference added here should already appear as an in-text citation somewhere in the final proposal. Before final submission, we'll do a pass checking that author names, years, titles, and links are accurate and consistent with the reference list in the report itself.
