# Proposed Evaluation Metrics

The proposed system will be evaluated using four main metrics.

## Vulnerability Detection Coverage

Detection Coverage = Known Vulnerabilities Detected / Total Known Vulnerabilities x 100%

## False Positive Proportion

False Positive Proportion = False Positive Findings / Total Reported Findings x 100%

## Severity Coverage

Severity coverage measures whether each testing configuration identifies vulnerabilities across different severity levels.

## Testing Time

Testing time measures the duration required to complete each testing configuration.

## Comparison

Three configurations will be compared:

1. SAST only
2. DAST only
3. Integrated SAST and DAST
