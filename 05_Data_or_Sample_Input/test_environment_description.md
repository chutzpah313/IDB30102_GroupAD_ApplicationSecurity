# Controlled Test Environment

The proposed system will be evaluated using a controlled automotive oriented application testbed.

The testbed may represent functions such as:

- infotainment services
- vehicle information services
- telematics related APIs

The application will run locally inside Docker.

Known vulnerabilities will be included in the test environment so that detection coverage can be measured.

The environment will not interact with live vehicles, production systems, manufacturer infrastructure or third party services.
